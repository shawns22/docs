# docs

二期软件的开发记录相关文档。

## 目录结构

```
docs/
├─ Fixs/          问题修改记录（fix-<编号>/，每包含 spec.md + tasks.md）
├─ Refs/          编号文档（背景、架构、流程标准、历史分析）
└─ Tasks/         各阶段任务过程稿（task-<任务号>/，每包含 spec.md + tasks.md）
```

## 使用约定

- 新增编号文档（背景、架构、流程标准、历史分析）放入 `Refs/`，命名为 `NN-<标题>-<YYYYMMDD>.md`
- 新增问题修改记录放入 `Fixs/fix-<编号>/`，每包含 `spec.md` + `tasks.md`
- 新增阶段任务过程稿放入 `Tasks/task-<n>/`，每包含 `spec.md` + `tasks.md`
- 文档与代码冲突时**以代码为准**
